## 📌 Overview

**Tailwind BaseUI Templates** is an accessible, developer-first UI component foundation built for shipping fast, beautiful web applications. Combining the headless unstyled power of `@base-ui/react` and `shadcn` with modern Tailwind CSS styling, it provides copy-paste ready, responsive building blocks.

- 🌐 **Live Showcase:** [tailwind-baseui-templates.vercel.app](https://tailwind-baseui-templates.vercel.app)

---

## ✨ Features

- ⚡ **Next.js App Router Architecture:** Server components, streaming, and lightning-fast route transitions.
- 🧩 **Accessible Primitives:** Powered by `@base-ui/react` ensuring ARIA compliance, full keyboard navigation, and focus management.
- 🎨 **Utility-First Styling:** Clean, composable styling with Tailwind CSS and `clsx` / `tailwind-merge`.
- 🌓 **Design Token System:** Modular theme variables for seamless dark/light mode transitions.
- 📦 **Zero-Bloat Production Bundle:** Tree-shakeable components optimized with TypeScript 5.7.

## 🚀 Quickstart

### Prerequisites
- Node.js (v18.17+ or v20+)
- pnpm or npm

### Setup

```bash
# 1. Clone repository
git clone https://github.com/Janjua004/tailwind-baseui-templates.git
cd tailwind-baseui-templates

# 2. Install dependencies
pnpm install
# or: npm install

# 3. Start development server
pnpm dev
# or: npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the templates.
